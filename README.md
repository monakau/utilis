# utils

Personal collection of local working tools. Each tool lives in its own folder under `tools/` with whatever language/runtime fits it best.

## Layout

```
tools/
  <tool-name>/     # one tool, self-contained (own package.json, deps, etc.)
```

## Adding a tool

Create a new folder under `tools/` named after the tool. Keep it self-contained — its own dependency manifest, its own README if it needs explaining.
